Khởi Tạo Tham Số Dạng Fluent & Rào Chắn Kiểm Định Fail-Fast
Loại Bỏ Telescoping Constructor 10 Tham Số
Chuỗi phương thức cấu hình liên tiếp (Fluent Method Chaining) SimulationConfiguration.builder()
Bước 1 .builder() Khởi tạo đối tượng Builder tạm
Bước 2 .windowSize(1000) Kích thước cửa sổ trượt
Bước 3 .threshold(0.02) Ngưỡng tiện ích tối thiểu
Bước 4 .decayRate(0.95) Hệ số suy giảm tiện ích
Bước 5 .batchInterval(100) Tần suất kiểm tra trôi dạt
↓ Gọi phương thức kết thúc: .build()
Rào Chắn Kiểm Định Fail-Fast (Validation Gate)
  • ✓ windowSize > 0 (Cửa sổ phải hợp lệ)
  • ✓ 0 < minUtilityRatio < 1 (Ngưỡng tiện ích)
  • ✓ 0 < decayRate <= 1.0 (Hệ số suy giảm)
⚠ Nếu vi phạm ➔ Ném ngay IllegalArgumentException
