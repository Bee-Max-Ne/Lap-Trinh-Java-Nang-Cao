## Follow-up: GUI input thread-safety

After source review found that the background worker read the Running Example
text area, `onRunSimulation()` now snapshots its text on the EDT and passes the
immutable `String` to `SimulationWorker`. A clean compile of all 36 Java files
and the StrategyInjectionTest, SimulationServiceEventTest, DatasetServiceTest,
DataLayerTest, FinalValidationSuite, BaselineRunner, EndToEndChessRunner, and
DriftPairBenchmark runners all passed after this change.

The Swing application was not launched interactively in this follow-up. The
fix is source-reviewed and compile-verified; desktop lifecycle and rendering
remain unverified. FullBenchmarkSuite was not rerun because this GUI-only change
does not affect the algorithm or benchmark path.

## Final GUI smoke-test follow-up

Recorded: 2026-10-02.

The GUI was launched with `java -cp out huddtds.demo.HUDD_TDS_GUI`; its Swing
window opened and reported as responsive. Visual inspection showed transaction
progress, process log output, metric cards, and chart rendering during/completing
a Running Example execution. A bounded run configured with `Max Tx = 20`
reported 21 processed transactions, exposing an off-by-one in the GUI limit
check. The check now stops before incrementing the TID/processed count when the
configured limit has already been reached.

After the fix, all 36 Java source files were recompiled into `out` and
FinalValidationSuite, StrategyInjectionTest, SimulationServiceEventTest,
DatasetServiceTest, DataLayerTest, BaselineRunner, and EndToEndChessRunner all
returned exit code 0. The running-example and selected Chess outputs matched
their recorded baseline comparisons. FullBenchmarkSuite was not rerun because
the change only affects the GUI transaction-limit counter.

The complete interactive lifecycle was not verified: PAUSE/RESUME/STOP/RESET,
filter/search behavior, and export were not reliably exercised in this agent
session. The GUI smoke-test status therefore remains NOT TESTED as a complete
end-to-end desktop check; the visual observations above are partial evidence
only, not a PASS claim.
